# Бот-планировщик для репетиторов (MVP)

Telegram-бот, в котором репетитор ведёт расписание уроков. Ученикам Telegram не нужен.

## Что умеет

- **Ученики**: имя, контакт, стоимость урока, регулярное расписание (редактор на кнопках: день → час → минуты).
- **Расписание**: «Сегодня / Завтра / Неделя», листание дней стрелками.
- **Уроки**: отмена, возврат, перенос (`завтра 18:00`, `пт 17:30`, `25.11 16:00`), разовые уроки.
- **Напоминания ученикам**: готовый текст (копируется нажатием) и кнопка «Отправить в WhatsApp»,
  которая открывает чат с учеником и уже вставленным текстом (через `wa.me`).
- **Утренняя сводка** (по умолчанию в 08:00; включается, выключается и настраивается в «⚙️ Настройки»):
  список уроков на день.

Учёт оплат пока убран из интерфейса. Таблица `payments` и методы в `db.py` остались, чтобы вернуть его позже.

## Структура

```
bot.py        — запуск, логирование, планировщик (сводки + продление расписания)
middlewares.py — лог действий пользователей, часовой пояс репетитора
backup.py     — бэкапы базы
admin.py      — команды владельца: /backup, /stats
handlers.py   — все хендлеры aiogram, клавиатуры, FSM
db.py         — SQLite (aiosqlite): схема и запросы
utils.py      — разбор дат/времени/расписания, форматирование
config.py     — настройки из переменных окружения
```

### Модель данных

| Таблица    | Зачем                                                                  |
|------------|------------------------------------------------------------------------|
| `tutors`   | репетиторы (Telegram user_id), время сводки                            |
| `students` | ученики репетитора, цена урока, флаг архива                            |
| `slots`    | регулярное расписание: день недели + время                            |
| `lessons`  | конкретные уроки; регулярные создаются из `slots` на 21 день вперёд   |
| `payments` | оплаты (пока не используется в интерфейсе)                             |

Главное решение здесь в том, что регулярные уроки «разворачиваются» в конкретные строки `lessons`.
Поэтому отмена или перенос одного урока — это просто изменение строки.
Поле `orig_day` + `UNIQUE(slot_id, orig_day)` не даёт перенесённому уроку создаться повторно.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
BOT_TOKEN=123:ABC .venv/bin/python bot.py
```

Переменные окружения: `BOT_TOKEN` (обязательно), `BOT_TZ` (по умолчанию `Europe/Moscow`),
`DB_PATH` (по умолчанию `tutor.db`).

### Как user-сервис systemd

`~/.config/systemd/user/tutor-bot.service`:

```ini
[Unit]
Description=Tutor scheduler Telegram bot
After=network-online.target

[Service]
WorkingDirectory=%h/tutor_bot
EnvironmentFile=%h/tutor_bot/.env
ExecStart=%h/tutor_bot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
```

`.env`:
```
BOT_TOKEN=123:ABC
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now tutor-bot
journalctl --user -u tutor-bot -f
```

## Логи

Каждое действие пишется одной строкой в консоль и в `logs/bot.log`
(до 5 файлов по 5 МБ, старые удаляются сами):

```
2026-11-20 20:18:14 INFO    actions: Иван (@ivan, id=123) — нажал [💵 Стоимость] (st:price:5) (12 мс)
```

```bash
tail -f logs/bot.log                 # смотреть в реальном времени
grep "id=123" logs/bot.log           # всё, что делал конкретный пользователь
grep -A20 "ОШИБКА" logs/bot.log      # ошибки с трейсбэком
```

В логах есть то, что пишут пользователи (имена и телефоны учеников), так что храни их так же бережно, как базу.

## Бэкапы

Каждый день в 03:30 (`BACKUP_TIME`) бот сам делает копию базы в `backups/tutor-ГГГГ-ММ-ДД.db.gz`
(хранятся последние 14) и присылает файл владельцу в Telegram. Для этого в `.env` нужен `ADMIN_ID`:

```
BOT_TOKEN=123:ABC
ADMIN_ID=123456789
```

Свой id можно найти в логе: строки вида `Имя (@ник, id=123456789) — …`.

Команды владельца: `/backup` — бэкап прямо сейчас, `/stats` — сколько репетиторов и учеников.

Восстановление из бэкапа:

```bash
systemctl --user stop tutor-bot        # или останови bot.py вручную
cp tutor.db tutor.db.broken
gunzip -c backups/tutor-2026-11-20.db.gz > tutor.db
systemctl --user start tutor-bot
```
